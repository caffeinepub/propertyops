# Specification

## Summary
**Goal:** Launch a single-page PropertyOps® B2B marketing homepage that positions standardized, documented property operations and captures inbound consultation requests.

**Planned changes:**
- Build a single-page homepage with the required section order and copy direction: Hero (with exact headline/subheadline/CTA), How It Works (3 steps), Technology & Systems (explicitly supports ops and does not replace people), Services (exactly three), Quality Control, Contractor Model, Trust/Differentiators, and Franchise Teaser.
- Implement “Request a Service Consultation” lead-capture flow (modal or embedded) with basic client-side validation, consent checkbox, success state, and backend persistence (timestamp + unique ID) plus a query method for future internal admin use.
- Apply a clean, modern, professional visual theme (dark blue/slate/white with subtle green accents), using non-futuristic operational icons and at least one process/flow diagram; serve all generated visuals as static frontend assets.
- Add SEO fundamentals: page title, meta description, semantic headings, and natural inclusion of the provided B2B keyword phrases while keeping calm, operational tone.
- Add credibility-forward messaging (U.S.-based operations team, standardized workflows, digital checklists, photo documentation) without legal/immigration guarantees.

**User-visible outcome:** Visitors can read a professional, operationally-focused PropertyOps® homepage and submit a consultation request via an on-page flow, receiving a clear confirmation after successful submission.
